# Daily Check-in Badge

A Base MiniApp that rewards users with NFT badges for daily check-ins.

## Features
- Daily check-in with 24-hour cooldown
- Progressive badge system (Starter → Bronze → Silver → Gold → Diamond)
- Streak tracking
- Auto-mint NFT badges at milestones

## Tech Stack
- Next.js 15
- Wagmi v2
- Viem v2.45+
- Base (Sepolia)

## Contract
- Address: `0xe17d104d62208128217b5ce10031b1b5682fcc64`
- Type: ERC-721

npm install
npm run dev
